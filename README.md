# Spazio Perdizes Prototype

Crie um protótipo visual PREMIUM de uma landing page para o SPAZIO PERDIZES, um salão de beleza localizado na Rua Tucuna, 710 — Perdizes, São Paulo.

IMPORTANTE:

Este projeto é um PROTÓTIPO COMERCIAL para apresentar ao cliente.

Neste momento NÃO quero backend, React, Next.js, banco de dados, WordPress, CMS ou qualquer framework.

Entregue somente:

HTML
CSS
JavaScript vanilla mínimo, somente se realmente necessário

O código deve ser organizado e fácil de transformar posteriormente em uma aplicação real.

Nome:
SPAZIO PERDIZES

Instagram:

O salão possui uma presença forte no Google e Instagram, com aproximadamente 4,7 estrelas e mais de 300 avaliações no Google.

O negócio trabalha com diferentes serviços de beleza, incluindo cabelo, manicure/pedicure, alongamento de unhas, tratamentos capilares, maquiagem, sobrancelhas, depilação e tratamentos de beleza.

O Instagram possui bastante conteúdo e aproximadamente 3 mil seguidores.

Existem avaliações reais destacando:

atendimento;
profissionais específicos;
manicure;
cabelo;
alongamento de fibra;
terapia capilar;
ambiente;
experiência da equipe.

Use essas informações para construir uma experiência que pareça pertencer a um negócio REAL.

NÃO invente informações específicas como preços, promoções, nomes de serviços que não estejam confirmados ou depoimentos falsos.

OBJETIVO

A landing page precisa fazer uma cliente pensar:

"Quero conhecer esse lugar."

E depois:

"Quero agendar."

O site não deve parecer um catálogo de serviços.

Ele deve vender a EXPERIÊNCIA do Spazio.

DIREÇÃO CRIATIVA

NÃO faça um site genérico de salão.

EVITE COMPLETAMENTE:

template rosa de salão;
excesso de gradientes;
ícones genéricos;
cards iguais;
aparência de template de Elementor;
fontes excessivamente "femininas";
emojis;
stock photos genéricas;
hero com "Bem-vinda ao Spazio";
três cards de serviços lado a lado;
visual de site barato.

Quero uma direção visual semelhante a um editorial de moda/beleza.

Pense em:

fashion editorial + beauty boutique + salão premium.

A identidade deve parecer sofisticada, contemporânea e um pouco ousada.

DIREÇÃO VISUAL

Use principalmente:

preto;
off-white;
tons naturais;
cinza quente;
detalhes metálicos discretos;
tipografia serif sofisticada combinada com uma sans-serif moderna.

Evite deixar tudo preto.

A página deve ter bastante espaço negativo.

Use tipografia como elemento de design.

Alguns títulos podem ser enormes e ocupar grande parte da tela.

A composição deve parecer propositalmente editorial.

HERO

O hero deve ser IMPACTANTE.

Não quero um hero convencional.

Estrutura sugerida:

SPAZIO
PERDIZES

BELEZA,
DO SEU JEITO.

ou uma frase conceitual semelhante.

Adicionar:

Perdizes · São Paulo

e CTA:

"Agendar atendimento"

Outro CTA secundário:

"Conhecer o Spazio"

O hero deve utilizar uma imagem grande de beleza/cabelo/unhas com tratamento editorial.

IMPORTANTE:

Se não houver imagens reais disponíveis no projeto, use imagens externas apenas como placeholders claramente identificáveis no código ou URLs de imagens de alta qualidade.

Priorize imagens que tenham aparência de editorial de moda e não stock photo de banco de imagens.

SEÇÃO "O SPAZIO"

Não criar uma seção tradicional "Sobre nós".

Criar uma seção curta e editorial contando a experiência.

Exemplo de conceito:

"Mais do que um horário na agenda."

"O Spazio é um lugar para desacelerar, cuidar de você e sair se sentindo ainda melhor."

Mas NÃO copie exatamente esse texto se conseguir criar algo melhor.

O texto deve ser curto.

Muito espaço em branco.

Uma fotografia grande.

SERVIÇOS

Não utilizar uma grade convencional de cards.

Quero uma apresentação mais sofisticada.

Por exemplo:

01
CABELO

02
UNHAS

03
BELEZA

04
CUIDADOS

Cada item pode ocupar uma área grande da tela e revelar informação visualmente.

Pode usar hover para desktop.

A navegação precisa ser elegante.

PROFISSIONAIS

Essa seção é importante.

As avaliações reais mencionam profissionais como:

Patrícia
Dani

Silvana

Edi

NÃO invente cargos ou especialidades para essas pessoas.

Caso utilize os nomes, apresente-os apenas como profissionais do Spazio ou crie uma área visual preparada para receber posteriormente foto + especialidade + Instagram.

A seção deve transmitir:

"Você não está escolhendo apenas um salão. Está escolhendo profissionais."

PROVA SOCIAL

Criar uma seção visualmente forte utilizando avaliações reais.

Utilizar apenas trechos fornecidos no briefing.

Exemplos de conceitos encontrados nas avaliações:

"superou minhas expectativas"
atendimento muito bom
ambiente agradável
profissionais excelentes
equipe acolhedora

Não inventar avaliações.

Não colocar 20 depoimentos.

Escolher 3 ou 4 e apresentá-los como editorial.

Mostrar também:

4,7 ★
+300 avaliações

Google

Isso deve funcionar como prova de confiança.

INSTAGRAM

O Instagram é uma parte importante da marca.

Criar uma seção visual que pareça uma extensão do Instagram.

Usar uma composição de imagens assimétrica:

imagem grande
imagem pequena
imagem pequena
imagem vertical

Não fazer simplesmente uma grade 3x3.

Adicionar:

@salaodebelezaemperdizes

"Ver mais no Instagram"

CTA FINAL

O CTA final deve ser forte.

Não usar:

"Entre em contato conosco!"

Criar algo mais elegante.

Exemplo:

SEU PRÓXIMO
MOMENTO COMEÇA AQUI.

Perdizes · São Paulo

[AGENDAR ATENDIMENTO]

WhatsApp:
(11) 96564-1010

"Como chegar"

que pode apontar posteriormente para Google Maps.

HEADER

Desktop:

SPAZIO

Serviços
Experiência
Profissionais
Instagram

[Agendar]

Header inicialmente transparente sobre o hero.

Ao rolar, pode ganhar fundo sólido.

Mobile:

Logo
menu hamburger
botão de agendamento.

MICROINTERAÇÕES

Adicionar pequenas interações sofisticadas:

hover em serviços;
imagens com zoom muito sutil;
transições suaves;
reveal de elementos no scroll;
underline animado;
header mudando durante o scroll.

NÃO exagerar.

Nada de animações chamativas.

O objetivo é parecer um site de marca premium.

RESPONSIVIDADE

Precisa funcionar muito bem em:

Desktop
Tablet
Mobile

Mobile NÃO deve simplesmente ser o desktop empilhado.

Redesenhe a composição para mobile.

QUALIDADE TÉCNICA

Use:

HTML semântico;
CSS organizado;
variáveis CSS;
acessibilidade básica;
alt nas imagens;
boa hierarquia de headings;
performance razoável;
lazy loading nas imagens abaixo do primeiro viewport;
nenhum framework.

Não coloque tudo em um único bloco CSS desorganizado.

Estruture o CSS por seções.

IMPORTANTE SOBRE O RESULTADO

Quero que, ao abrir o HTML no navegador, a primeira impressão seja:

"Isso parece um site de uma marca de beleza premium."

E não:

"Isso parece um template de salão feito em 20 minutos."

O design precisa ter personalidade própria.

Tome decisões de direção de arte.

Não fique preso à estrutura tradicional:

Hero → 3 cards → Sobre → Serviços → Depoimentos → Contato.

Quebre essa estrutura.

Crie ritmo visual.

Use assimetria, tipografia grande, imagens em diferentes proporções e bastante espaço negativo.
